How scoring works

Each published rule change has one draft with an error and one that preserves the rule. A pair passes when the reviewer flags the error and passes the faithful draft. Missing decisions and abstentions earn no credit.

This is a small, public practice set with authored examples. Real-world performance needs assessment on unseen cases.
