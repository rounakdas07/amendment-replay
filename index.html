Method, answer key and limits

Each of the 12 published changes has one conflicting draft and one faithful paraphrase. The drafts and answer key were written for this pack. A pair is correct only when both decisions are right. Missing decisions and abstentions earn no credit. A false alarm is a flag on a faithful draft.

This public practice set tests agreement with 12 selected rules. Its scores do not establish clinical performance. No commercial reviewer has been evaluated here.
